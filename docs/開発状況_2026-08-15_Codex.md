# LunaStack 開発状況（2026-08-15 / Codex作業後）

## 今回完了した項目

- M7解析性能
  - 通常モードの品質評価・グローバルアライメントをフレーム単位で並列化
  - AP別ZNCC相関をGCDで並列化
  - 低メモリモードはmmap再マップと競合しないよう逐次読み込みを維持
  - `MADV_SEQUENTIAL`をSER/AVIの通常読み込みにも適用
- エンジンとGUIの設定差分
  - 品質指標: 勾配エネルギー / FFT周波数帯パワー比
  - 選択方式: 割合 / 枚数
  - 輝度正規化: ON / OFF
  - 加算方式: 単純平均 / 品質重み付き平均 / MADベースσクリップ
- 入出力
  - 決定論的な16bit PNG（グレースケール/RGB）
  - CLIは出力拡張子`.png`でPNGを選択
  - GUIの単発保存・バッチ・自動命名へPNGを接続
- GUI小改善
  - 処理終了時に進捗バーを非表示にし、完了直後の満杯表示を解消
- アプリアイコン
  - 1024px原本と全サイズを含む`LunaStack.icns`を作成
  - `CFBundleIconFile`とCMakeのバンドルリソースへ設定

## 主な検証

- Releaseビルド成功
- `ctest --output-on-failure`: 163/163件、通常・Universal 2とも全合格
- 300フレーム・MAP 1パス: 10.73秒から3.41秒へ短縮（約3.15倍）
- 上記の変更前後TIFFはSHA-256一致
- 木星4617フレーム・既定2パス: 1分57.64秒で完走（M7の5分以内を達成）
- 実SERで以下を完走
  - FFT周波数品質 + 固定12枚 + 品質重み付き + 16bit PNG
  - 固定12枚 + σクリップ + 1.5倍Drizzle + 16bit PNG
- PNGはmacOS `sips`と`file`で448×448、RGB、16bitとして認識
- アプリバンドルに`LunaStack.icns`が入り、Info.plist参照が一致
