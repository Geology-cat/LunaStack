# LunaStack 開発状況（2026-08-15 / Codex作業後）

## 今回完了した項目

- M7解析性能
  - 通常モードの品質評価・グローバルアライメントをフレーム単位で並列化
  - AP別ZNCC相関をGCDで並列化
  - 低メモリモードはmmap再マップと競合しないよう逐次読み込みを維持
  - `MADV_SEQUENTIAL`をSER/AVIの通常読み込みにも適用
- エンジンとGUIの設定差分
  - 品質指標: 勾配エネルギー / FFT周波数帯パワー比
  - 選択方式: 割合 / 枚数
  - 輝度正規化: ON / OFF
  - 加算方式: 単純平均 / 品質重み付き平均 / MADベースσクリップ
- 入出力
  - 決定論的な16bit PNG（グレースケール/RGB）
  - CLIは出力拡張子`.png`でPNGを選択
  - GUIの単発保存・バッチ・自動命名へPNGを接続
- GUI小改善
  - 処理終了時に進捗バーを非表示にし、完了直後の満杯表示を解消
  - キュー右クリックへFinder表示・削除・選択ファイルだけの処理を追加
  - 警告バナーへlittle/big・12bit解釈の直接操作と閉じる操作を追加
  - フレームスライダーを140ptへ拡幅し、ステータスボタンを可変幅化
- アプリアイコン
  - 1024px原本と全サイズを含む`LunaStack.icns`を作成
  - `CFBundleIconFile`とCMakeのバンドルリソースへ設定
- 多言語化
  - `ja.lproj` / `en.lproj`を追加し、メニュー・設定・状態・通知を日本語／英語表示
  - `NSBundle`で英語リソースの実選択を確認
- AVI MJPEG
  - OSデコーダに依存しない8bitベースライン逐次JPEGデコーダを追加
  - 4:4:4 / 4:2:2 / 4:2:0、再スタートマーカー、DHT省略時の既定表に対応
  - progressive JPEG・複数スキャンは明示的に拒否
- GitHub管理
  - 非公開リポジトリ `Geology-cat/LunaStack` を作成
  - `origin` を `https://github.com/Geology-cat/LunaStack.git` に設定
  - 既定ブランチ `main` を追跡し、ローカルとGitHubのコミットを同期
