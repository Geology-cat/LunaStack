# LunaStack 開発状況（2026-08-15 / Codex作業後）

## 今回完了した項目

- M7解析性能
  - 通常モードの品質評価・グローバルアライメントをフレーム単位で並列化
  - AP別ZNCC相関をGCDで並列化
  - 低メモリモードはmmap再マップと競合しないよう逐次読み込みを維持
  - `MADV_SEQUENTIAL`をSER/AVIの通常読み込みにも適用
- エンジンとGUIの設定差分
  - 品質指標: 勾配エネルギー / FFT周波数帯パワー比
  - 選択方式: 割合 / 枚数
  - 輝度正規化: ON / OFF
  - 加算方式: 単純平均 / 品質重み付き平均 / MADベースσクリップ
- 入出力
  - 決定論的な16bit PNG（グレースケール/RGB）
  - CLIは出力拡張子`.png`でPNGを選択
  - GUIの単発保存・バッチ・自動命名へPNGを接続
- GUI小改善
  - 処理終了時に進捗バーを非表示にし、完了直後の満杯表示を解消
- アプリアイコン
  - 1024px原本と全サイズを含む`LunaStack.icns`を作成
  - `CFBundleIconFile`とCMakeのバンドルリソースへ設定
- 多言語化
  - `ja.lproj` / `en.lproj`を追加し、メニュー・設定・状態・通知を日本語／英語表示
  - `NSBundle`で英語リソースの実選択を確認
- AVI MJPEG
  - OSデコーダに依存しない8bitベースライン逐次JPEGデコーダを追加
  - 4:4:4 / 4:2:2 / 4:2:0、再スタートマーカー、DHT省略時の既定表に対応
  - progressive JPEG・複数スキャンは明示的に拒否
- GitHub管理
  - 非公開リポジトリ `Geology-cat/LunaStack` を作成
  - `origin` を `https://github.com/Geology-cat/LunaStack.git` に設定
  - 既定ブランチ `main` を追跡し、ローカルとGitHubのコミットを同期

## 主な検証

- Releaseビルド成功
- `ctest --output-on-failure`: 単体172/172件、通常・Universal 2ともCTest 3/3全合格
- 300フレーム・MAP 1パス: 10.73秒から3.41秒へ短縮（約3.15倍）
- 上記の変更前後TIFFはSHA-256一致
- 木星4617フレーム・既定2パス: 1分57.64秒で完走（M7の5分以内を達成）
- 実SERで以下を完走
  - FFT周波数品質 + 固定12枚 + 品質重み付き + 16bit PNG
  - 固定12枚 + σクリップ + 1.5倍Drizzle + 16bit PNG
- PNGはmacOS `sips`と`file`で448×448、RGB、16bitとして認識
- アプリバンドルに`LunaStack.icns`が入り、Info.plist参照が一致
- ffmpeg生成4:4:4 MJPEGは参照デコード比PSNR 50.98dB・最大差3
- 実写木星由来4:2:0 MJPEG 100フレームで抽出3点と25枚スタックを完走（2.55秒）
- 同MJPEGの同一フレーム抽出・同一スタックを各2回行い、SHA-256がそれぞれ一致
- Universal 2はx86_64 / arm64を含み、最低OS表記は10.13 / 11.0
- GitHubリポジトリは非公開、既定ブランチは`main`、ローカル`HEAD`と`origin/main`のSHA-1一致を確認
